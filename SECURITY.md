# Security Policy

This repository is a public release-artifact mirror for HypeProof Studio.

Do not open a public issue for secrets, installer compromise, release asset
tampering, or token leaks. Contact:

- GitHub: `@jayleekr`
- GitHub: `@JeHyeong2`

Release assets should be treated as immutable. If an asset is compromised or
incorrect, publish a new release/tag from the source repository rather than
silently replacing the old artifact.
